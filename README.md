# welcome

모바일 청첩장 한 페이지. 빌드 도구 없이 `index.html` 한 파일로 되어 있고, GitHub Pages로 배포됩니다.

- 공개 주소: https://a01051998767.github.io/welcome
- 내용을 바꾸려면 `index.html` 아래쪽 `const CONFIG = { ... }` 블록만 고치면 됩니다.
- 참석 의사는 구글 스프레드시트로 바로 들어옵니다. 연결 방법은 아래에 있습니다.
- 만드는 방법과 지켜야 할 규칙은 [CLAUDE.md](CLAUDE.md)에 적어 두었습니다.

## 참석 의사 접수 연결하기

하객이 청첩장 화면에서 "참석 의사 보내기"를 누르면 입력창이 열리고, 보낸 내용이
구글 스프레드시트에 한 줄씩 쌓입니다. 구글 폼은 쓰지 않습니다.

준비는 **시트 주인 계정에서 한 번만** 하면 됩니다.

1. 하객 리스트 스프레드시트를 엽니다.
2. **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 지우고 이 저장소의 [`apps-script.gs`](apps-script.gs) 전체를 붙여 넣습니다.
   맨 위 `spreadsheetId`가 본인 시트 주소의 `/d/` 와 `/edit` 사이 값과 같은지 확인합니다.
4. 저장한 뒤 함수 선택에서 `setup`을 골라 한 번 실행하고, 구글 권한을 승인합니다.
   시트에 `RSVP` 탭과 제목 줄이 생기면 성공입니다.
5. **배포 → 새 배포 → 웹 앱**을 고르고 **실행 사용자: 나**, **액세스 권한: 모든 사용자**로
   배포합니다. 이렇게 해야 하객이 로그인 없이 답을 보낼 수 있습니다.
6. 끝이 `/exec` 인 주소를 복사해 `index.html` 의 `CONFIG.rsvpEndpoint` 에 넣습니다.
   (`/dev` 주소나 스프레드시트 주소를 넣으면 안 됩니다.)
7. 로그아웃한 창에서 그 `/exec` 주소를 열어 `{"ok":true,"service":"wedding-rsvp"}` 가
   보이는지 확인한 뒤, 청첩장에서 테스트로 한 번 보내고 시트에 줄이 생기는지 봅니다.

주소를 넣기 전까지는 입력창이 열리되 "준비 중입니다"라고 안내하고 아무것도 보내지 않습니다.

시트 열은 `번호 / 접수 날짜 / 성함 / 1부 / 2부 / 3부 / 미리 알려주실 것 / 연락처 / 요청 ID`
순서입니다. 제목 줄의 순서를 바꾸면 저장이 멈추니 그대로 두세요.

받는 항목을 바꿔서 `apps-script.gs` 를 다시 붙여 넣었다면 제목 줄도 맞춰야 합니다.
접수된 줄이 없으면 `setup` 만 실행하면 제목 줄이 새 항목으로 다시 써집니다.
이미 받은 줄이 있으면 함수에서 **`resetSheet`** 를 골라 한 번 실행하세요.
기존 탭은 `RSVP_20261024_2114` 처럼 날짜가 붙은 이름으로 보관되고 새 `RSVP` 탭이 생깁니다.

### 접수가 안 될 때
Apps Script 왼쪽 메뉴의 **실행 기록**에 실패한 실행과 오류 메시지가 남습니다.
- `Unexpected sheet columns` — 제목 줄이 코드와 다릅니다. 위 `resetSheet` 를 실행하세요.
- `Invalid side` 처럼 없는 항목 이름이 보이면 — 배포된 코드가 옛날 버전입니다.
  `apps-script.gs` 를 다시 붙여넣고 저장한 뒤 **새 버전**으로 배포하세요.
- 실행 기록에 아무것도 없으면 요청이 서버까지 오지 못한 것입니다. 배포의
  **액세스 권한: 모든 사용자** 설정을 확인하세요.
`apps-script.gs` 를 고친 뒤에는 **배포 → 배포 관리 → 수정 → 새 버전**으로 기존 배포를
업데이트해야 주소가 그대로 유지됩니다.
